네이버 블로그는 자동 발행이 불가능합니다. 2020년 5월 글쓰기 API 가 종료됐습니다. 앱은 서식이 살아 있는 본문을 만들어 복사까지 해 드리고, 게시는 사람이 합니다. 게시 후 URL 만 붙여넣으면 성과 추적 대상에 들어갑니다.

연동 설정

설정값을 넣으면 연결·토큰 갱신·계정 탐지·권한 확인까지 자동으로 처리합니다. 앱 검수 제출과 승인만 사람이 합니다 — 그 상태도 여기서 함께 봅니다.

자동으로 되는 것 — OAuth 연결 · 장기 토큰 교환과 갱신 · 페이지/인스타 계정 탐지 · 권한 부여 상태 실시간 확인 · 필수 입력 누락 점검
사람이 해야 하는 것 — Meta 개발자 대시보드에서 앱 검수 제출. 승인을 호출하는 API 는 없습니다(심사는 Meta 가 사람이 합니다).

모델 프로필

브랜드에 반복 등장하는 모델의 고정값과 금지 조건입니다. 규칙은 쌓기만 하고 지우지 않습니다 — 한 번 겪은 문제가 다시 나오지 않게 합니다.
